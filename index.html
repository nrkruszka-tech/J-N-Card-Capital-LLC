📖 Playbook

🌙 2 AM Target window

  • Signed in, payment + address saved before 2:00. ETBs go in <90 seconds.
  • Refresh the product links above directly — search caches out-of-stock longer.
  • Add-to-cart on the hour even if the page looks dead; checkout can complete later. Don't clear a hung cart — retry.
  • Backend load ≠ same-night drop (June SPC slipped a night). Friday is the backup window.
  • Watch #target-scraper the evening before: new SKUs loading = drop within 1–2 nights.

🏪 Pokémon Center queues

  • Weekdays ~10am–4pm ET (cluster 11–1); set-release nights drop overnight 12–5am ET.
  • Separate accounts = separate queue slots — you and Jackson each queue independently.
  • High queue number ≠ loss; drops run hours as carts abandon. Never auto-checkout (bans).

💰 Sell-side rules

  • BIN + Best Offer default. Price from 30–60d sold medians (130point for best-offer truth).
  • Offer rules: decline <80% · accept ≥92% · counter between. List Sundays.
  • Route: eBay = slabs $100–1k and $1k+ (halved FVF) · Whatnot = sealed · TCGplayer = modern raw <$50 · shows = fee-free exits.
  • Log every buy in the Flip Log with a receipt photo — that's the LLC's COGS record.
